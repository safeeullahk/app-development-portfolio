Featured project 01

School Manager

Multi-Tenant School Management SaaS

FlutterDartSupabasePostgreSQL

Overview

A multi-tenant school management application developed using Flutter and Supabase to manage school administration and academic operations. Each school operates as its own tenant, with role-based access for administrators and teachers.

Architecture & implementation

  • Flutter and Dart frontend
  • Supabase backend on PostgreSQL
  • Multi-tenant data architecture
  • Role-based admin and teacher workflows
  • Provider and ChangeNotifier state management
  • Separation of UI and business logic
  • Offline-first teacher attendance entry, syncing when connectivity returns

Main features & modules

Admin dashboard
Teacher workflows
Student management
Class management
Subject management
Attendance management
Examination management
Fee management
School reporting
Supabase authentication
Role-based access control
Row Level Security (RLS)

Technical challenges

Designing reliable offline-first attendance entry so teachers can record attendance without connectivity and have it synchronise cleanly afterwards. Enforcing tenant isolation on PostgreSQL with Row Level Security while keeping admin and teacher workflows distinct.

Featured project 02

FilCon

Convert files. Offline. Instantly.

FlutterDartC++OpenCVJNIAndroid NDK

Overview

FilCon is an offline-first Android application providing file conversion, PDF utilities and document scanning. Processing happens on-device, so the core workflows do not depend on a network connection.

Architecture & implementation

  • Flutter and Dart application
  • Native C++ image processing
  • OpenCV integration
  • Android NDK and JNI
  • Flutter MethodChannel communication
  • Native document edge detection
  • Perspective transformation

Main features

Offline file conversion
Image and document conversion
PDF creation
PDF merging
PDF compression
Multiple compression levels
Document scanning
Automatic document edge detection
Perspective correction
Image filters
Document image processing

Technical challenges

Bridging Flutter and native C++ through JNI and Android NDK, and exposing native document detection through MethodChannels. Keeping OpenCV processing fast enough for on-device scanning, including edge detection and perspective correction, while maintaining a fully offline pipeline.

Publishing status: Currently in Google Play closed testing. View on Google Play — access is limited to closed-testing testers.
