AI chat · Bring your own keys

KEYCHAT

Your AI models, your API keys.

KEYCHAT is a free, lightweight AI chat application where you connect your own AI providers. Add your own API key, point it at any OpenAI-compatible endpoint, set a model ID, and chat through one clean interface — instead of being locked into a single built-in model or provider.

Platform
Android · Flutter
Integration
OpenAI-compatible APIs
Status
Personal project
FlutterDartREST APIsOpenAI-compatible
  • Bring your own API key
  • Multiple model profiles
  • Custom Base URL per profile
  • Custom model ID per profile
  • Load models from an endpoint
  • Switch profiles and models
  • New chats with model selection
  • Keys kept on the device
  • Lightweight, user-controlled
GitHub profile ↗

Concept

Users configure their own AI access rather than depending on one built-in model. Each profile holds a name, an API key, a Base URL and a model ID, and models can be loaded directly from that endpoint.

Approach

A single lightweight chat surface over OpenAI-compatible REST APIs, with profile-based configuration so different providers, endpoints and models can be swapped without changing the app.
